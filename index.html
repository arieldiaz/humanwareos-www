There is an operating system for your computer.
There isn't one for you.

HumanwareOS is the layer above the software: your agents, your memory, your work and your life, running in one place you already know how to use. It runs on your own machine, in plain files, with no lock-in to any model or vendor.

The ladder

Each rung operates the one below it. Every rung got an operating system except the top one.

Humanware is the layer. HumanwareOS is the project that operates it.

The problem

Agents invert computing. We used to work for the tools. Now the tools work for us — and that is a bigger change than it sounds, because directing work is harder than doing it. More decisions, more context to hold, more threads running at once.

I tried the new tools built for this. Conductor. Superset. Paperclip. A whole workflow in Notion. Each one was a new surface to learn, a new place to check, and more friction exactly where I needed less of it.

The answer was already open

Slack solved this at my previous companies. Threads, channels, status, notifications, who is working on what — the model for coordinating parallel work already exists, and it is one most people already carry in their heads.

So the interface is not new. The agents move in behind it.

Human first

We got good at context engineering for agents. We are still years behind on context engineering for humans.

Everything through one surface

Mental load, running a team of agents, status, notifications, thread visibility, channel context — one place, not eight dashboards.

Parallel threads without going crazy

Many agents running at once is only useful if a person can still see the whole board. That constraint drives every design decision here.

Opinionated, and yours to change

Built for how I work, on purpose. It is a distro model: fork it, keep the spine, swap the parts that are about you.

No lock-in

Any harness, any model, memory as markdown in git repos. Nothing important lives inside a vendor you cannot export from.

Local models, tested honestly

Run sensitive work against local models. Privacy, cost, and real benchmarks instead of assumptions.

Personal and work, kept apart

Two domains, one system. The duality is a feature, not a compromise — it is the piece of this I keep coming back to.

What it does today

01

Two agents, two domains

Liv runs personal and life. Max runs the work. Separate memory, separate voice, one system — the 0 and the 1 of it.

02

Status you can read at a glance

An emoji language on every thread: lifecycle state, which agent has it, which harness ran it, which model answered. You know where a thread stands without opening it.

03

It builds itself in the open

Stats, security posture, token spend, live sessions — the system reports on its own operation, and the reports are part of the product.

04

Artifacts, published

Anything an agent makes can become a real page on the web: internal reference one minute, a shareable link the next. Archived, with provenance coming.

05

Any integration

If it has an API, it can be a channel, a command, or a scheduled job. The runtime is the adapter layer.

Architecture

Deliberately boring, deliberately replaceable. The human sits in front of Slack; everything else runs on one machine at home.

the whole system, on hardware you own

  • Agents — definitions and memory

  • Any harness — Claude Code, Codex, OpenCode, Pi
  • Any model — Anthropic, OpenAI, local, OpenRouter
  • Unified memory — git repos, markdown files
  • Doppler — key management
  • GitHub — code, one thread per session
  • Cloudflare — custom domains, automated

Three things you pay for, and they are worth separating: the framework, which is free and open; the products it drives, which you probably already pay for; and running it, which is your model spend plus a machine in the corner of a room.

Where this goes

This is v0 of a system I use every day for real work and a real life. The open question I keep circling is where the value actually accrues as agents get better — in the models, in the harnesses, or in the accumulated context of one particular person. I am betting on the last one, and building as if that is true.
