The inversion

We used to work for technology.
Agents make technology work for us.

That should feel freeing. Instead, most agent tools add tabs, dashboards, prompts, and cognitive load. HumanwareOS starts from the human: one familiar command surface, visible parallel work, and a system that remembers why—not just what.

Why Slack

The operating room was already built.

Slack already knows how to run a team. HumanwareOS turns that proven coordination layer into a command surface for your agents.

01

Parallel without chaos

One thread per mission. Work happens concurrently without shredding your attention.

02

Status at a glance

Emoji show who owns the work, whether it is moving, and which model and harness are running it.

03

Context has a place

Channels hold domains. Threads hold sessions. Notifications return you only when your judgment or hands are needed.

04

Everything comes back

Code, documents, diagrams, videos, and live artifacts return to the conversation with their provenance intact.

What it does today

Builds

Agents work in GitHub through Codex, Claude Code, OpenCode, Pi, or whatever comes next.

Operates

Sessions, security, model use, cost, and status stay visible instead of disappearing into black boxes.

Publishes

Turn the result into a web artifact, share a file, post a Loom, or archive it for later.

Remembers

Plain Markdown memory travels across agents, models, and vendors. The valuable context remains yours.

The stack

Local where it matters.
Portable everywhere.

A Mac mini runs the system. Slack reaches it securely through Tailscale. OpenClaw routes each thread to the right agent, harness, and model. GitHub holds the code and memory. Doppler holds the keys.

The opinionated parts

01Human first. Optimize the system for your attention, not the agent’s convenience.

02Avoid lock-in. Agents, models, harnesses, and interfaces must remain replaceable.

03Privacy is architectural. Run local models when the data, cost, or benchmark demands it.

04Context compounds. The system gets better because it writes lessons back into durable memory.

05Built in public. The system builds, observes, and explains itself as part of the work.
